# Padrão de Commits

Este projeto segue o seguinte padrão de commits:

## Tipos de Commits

- `feat`: Nova funcionalidade
- `fix`: Correção de bug
- `docs`: Alterações na documentação
- `style`: Formatação, ponto e vírgula faltando, etc; sem alteração de código
- `refactor`: Refatoração de código
- `test`: Adição de testes
- `chore`: Atualização de tarefas de build, configurações, etc; sem alteração de código

## Escopos

- `docs`: Documentação
- `infra`: Infraestrutura
- `backend`: Código do backend
- `frontend`: Código do frontend
- `tests`: Testes

## Exemplos

- `feat(docs diagrama-classes): adiciona diagrama de classes UML`
- `fix(docs): corrige link quebrado no README`
- `feat(tests): adiciona testes unitários para AnimalController`
- `feat(infra): configura Docker Compose`
- `feat(backend): implementa endpoint de cadastro de animais`
- `refactor(backend): melhora estrutura do código no serviço de vacinas`
